# 그냥 받아쓰기

영어(한/영 혼용) 수업을 실시간으로 받아쓰는 macOS 메뉴바 앱. 로컬 Whisper라 무료·무제한이고,
Antigravity(agy) 구독이 있으면 한국어 번역이 붙는다.

- **라이브(회색)**: parakeet-mlx 스트리밍 — 말한 지 1~3초 안에 화면에 뜬다 (초안, 확정 라인이 나오면 그 앞부분은 사라진다)
- **확정(검정)**: 침묵 경계로 자른 청크를 mlx-whisper large-v3-turbo로 재전사.
  단어가 잘리지 않고, 설정에서 고른 언어(기본 영어·한국어) 안에서만 언어를 판별한다
- **번역(주황 박스)**: agy(gemini flash-low)로 실시간 배치 번역
- **다듬기(버튼)**: 녹음을 끝낸 뒤 ✦ 다듬기를 누르면 전체 문맥과 강의자료로 원문의 오인식(잘못 들린
  단어·깨진 전문용어·말더듬·간투사)을 교정하고 번역을 다시 만든다. 번역문만큼 원문도 읽히게 정리한다.
  원본 문장은 `text0` 에 남겨 둔다
- **요약(탭)**: ✦ 요약을 누르면 강의 요약·정리본을 만든다 (다듬기가 안 됐으면 먼저 다듬는다). 상단
  번역/요약 탭으로 오간다. 강의 흐름대로 섹션을 나누고, 강의자료(PDF)가 있으면 오늘 어느 페이지를
  다뤘는지 섹션마다 붙인다. 요약이 생기면 왼쪽에 목차가 뜨고, 누르면 번역 탭에서는 그 대목의 원문으로,
  요약 탭에서는 그 섹션으로 바로 간다. `summary.md` 로 저장
- **강의자료 텍스트화**: 세션에 올린 PDF·이미지는 Gemini(3.8 flash)가 페이지별 텍스트로 바꿔
  `ctx_text/` 에 두고, 다듬기(용어 표기)와 요약(페이지 대응)이 참고한다. poppler(`pdftotext`)가 있으면
  Gemini 실패 시 대체
- 세션별 저장: `transcripts/<날짜_시각>/` — transcript.md(원문+번역)·lines.json·summary.md·audio.m4a

## 요구사항
Apple Silicon Mac(인텔 불가) · macOS 14+ · 램 16GB 권장(8GB는 라이브 끄고 사용) · 모델 3.8GB · [Homebrew](https://brew.sh) · (번역 원할 때만) [Antigravity CLI](https://antigravity.google)

## 설치

**방법 1 — 설치파일 하나 (권장, 친구용)**
[Releases](https://github.com/ChanchanCode/geunyang_dictation/releases/latest)에서
`geunyang-dictation-install.command`를 받는다. 다운로드한 스크립트는 macOS가 막으므로
**더블클릭 대신 터미널로 실행**한다 — 터미널(⌘Space → `터미널`)에 `zsh ` 를 치고 한 칸 띄운 뒤
받은 파일을 창에 드래그해 놓고 Enter. (Homebrew가 없으면 자동 설치하며 맥 암호를 한 번 묻는다.)

**방법 2 — 저장소에서**
```
git clone <repo-url> && cd geunyang_dictation && ./install.sh
```

설치 후 Spotlight(⌘Space)에서 **그냥 받아쓰기** 실행 → 뷰어가 브라우저에 열린다.

## 업데이트
새 버전이 있으면 앱을 열 때 **"새로운 업데이트가 있습니다"** 창이 뜬다. `업데이트`를 누르면
받아서 적용하고 앱을 다시 띄운 뒤 화면까지 알아서 새로고침한다. 사용자가 칠 명령은 없다.
`닫기`를 누르면 그 버전은 다시 묻지 않고, 톱니의 주황 점과 설정 맨 아래 버튼으로 언제든 할 수 있다.
녹취(`transcripts/`)와 설정은 그대로 남고, 녹음 중에는 잠긴다.

업데이트 기능이 없던 옛 설치본(2026-09-04 이전 배포분)은 한 번만 아래를 터미널에 붙여넣으면 된다.
그 뒤부터는 앱이 알아서 한다.
```
cd ~/Downloads && curl -fsSL -o gy-install.command "$(curl -fsSL https://api.github.com/repos/ChanchanCode/geunyang_dictation/releases/latest | python3 -c 'import json,sys;print(next(a["browser_download_url"] for a in json.load(sys.stdin)["assets"] if a["name"].endswith(".command")))')" && zsh gy-install.command
```
(`releases/latest/download/...` 짧은 경로는 CDN 캐시 때문에 한동안 옛 파일을 주므로 쓰지 않는다.)

배포하는 쪽은 `./release.sh 1.1.0 "바뀐 점"` 한 줄이면 된다 — 버전을 올리고 페이로드·설치기를
구워 GitHub Release 로 올린다. 앱은 릴리스 자산 `payload.tgz` 를 그 이름으로 찾으니 바꾸지 말 것.

## 사용
| 동작 | 방법 |
|---|---|
| 녹음 시작/일시정지/종료 | 메뉴바 냥 클릭 또는 뷰어 버튼 |
| 실시간 스크립트 보기 | 뷰어(http://127.0.0.1:8765), 자동으로 열림 |
| 지난 세션 | 뷰어 왼쪽 목록. 필터(⚙ 옆 슬라이더)에서 **날짜별 / 과목별** 묶기. 과목은 제목 앞 토큰('재무론2 2주차_1' → 재무론2)이나 세션에 지정한 과목 |
| 과목·제목 | 녹음 전 화면의 과목 칩(지난 세션에서 모은 과목)을 누르면 제목을 `과목_N주차(요일)` 꼴로 붙인다(예: 재무론2_2주차(화)). 주차는 기존 제목의 'N주차' 번호를 따라간다. PDF를 올리면 파일 이름으로 과목을 추정해 자동 지정(확신 없으면 비움) |
| 자료 폴더 | 설정(⚙) → 자료 폴더 선택. 과목이 정해진 세션에 올린 PDF·이미지를 `폴더/<과목>/` 에 복사한다(폴더 이름은 공백 무시로 맞춤, 없으면 생성). 같은 이름이 있거나 과목이 없으면 건너뛴다 |
| 라인 고치기 | 1초 길게 누르기·⌘ 클릭·우클릭으로 선택(Shift 클릭으로 범위) → 우클릭 메뉴나 하단 바에서 수정·복사·삭제. 더블클릭하면 바로 수정(원문/번역), Enter 저장·Esc 취소, Delete 키로 삭제 |
| 글자 드래그 | 누른 열만 선택된다 — 원문은 원문끼리, 번역은 번역끼리. 시각은 직접 눌러야 선택 |
| 맥락 넣기 | 녹음 전 맥락 박스에 한국어로 적거나 강의자료(PDF·이미지 여러 개)를 드롭 → Gemini(agy)가 영어 용어 노트로 정리. 받아쓰기 프롬프트·번역에 쓰인다 |
| 사용 언어 | 설정(⚙) 맨 위 칩에서 복수 선택(기본 영어+한국어). 전사 후보를 이 언어들로 제한한다 — 영어 강의 중 나온 한국어가 일본어·중국어로 찍히고 문장이 깨지는 걸 막는다. 하나만 고르면 감지를 건너뛴다 |
| 번역 모드 | 실시간(기본) / 다듬을 때만 / 끄기 |
| 라이브 끄기 | 설정(⚙)이나 메뉴바 → 라이브 미리보기. 회색 초안이 사라지는 대신 램 1.6GB를 아낀다 (8GB 맥 권장). 검정 확정 라인·번역은 그대로 |
| 예상 램 | 설정(⚙)의 메모리 게이지 — 녹음 중 예상 사용량과 내 램 대비 비율. 주황 구간이 라이브 층 몫이다 |
| 다듬기 | 녹음 종료 후 하단 ✦ 다듬기 (한 세션에 한 번, 녹음을 더 이어붙이면 다시 뜬다) |
| 요약 | 녹음 종료 후 하단 ✦ 요약 → 요약 탭. 다시 만들려면 요약 탭 위 '다시 만들기' |
| 다크 모드 | 뷰어 우상단 ◐ (자동/라이트/다크) |

## 문제 해결
- **마이크 권한**: 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 '그냥 받아쓰기' 허용
- **번역이 안 됨**: 터미널에서 `agy` 실행해 로그인. agy가 없으면 번역·다듬기·요약만 꺼지고 받아쓰기는 된다
- **모델**: 실시간 번역은 gemini-3.8-flash-low, 다듬기·요약·자료 변환은 gemini-3.8-flash-medium (`engine.py` 상단)
- **첫 시작이 느림**: 모델 2개(~3.2GB) 최초 1회 다운로드

## 구조
`app.py`(메뉴바+서버) · `engine.py`(오디오→2단 전사→번역→저장) · `viewer.html`(웹 뷰어)
